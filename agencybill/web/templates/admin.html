OpenRouter API key

A saved key overrides the environment variable and sends every agent call through OpenRouter. Clear it to fall back to OPENROUTER_API_KEY. The key is stored in the local database and is not written to the audit log.

Model

A saved model overrides AGENCYBILL_MODEL for every agent call. Use an Anthropic id such as claude-sonnet-4-6 or an OpenRouter slug such as anthropic/claude-sonnet-4.6 or openai/gpt-4.1.
